# 网络加速（v1.36）

NatsumeQuizMaster 只在一个场景需要访问 GitHub：**拉插件登记表**与**下载插件包**。
国内直连 `raw.githubusercontent.com` / `github.com` 经常超时或 TLS 被重置，
表现为「插件表一直是空」「安装转圈很久后失败」。v1.36 起所有这类请求都走
`lib/services/net/smart_http_client.dart`，按顺序自动换源，用户不需要手动重试。

## 一、回退顺序

**插件登记表 `registry.json`（6 个源，单源 8 秒）**

| 顺序 | 源 | 地址形态 |
| --- | --- | --- |
| 1 | 原始 | `raw.githubusercontent.com/Lamitis/Natsume-Registry/main/registry.json` |
| 2 | jsDelivr | `cdn.jsdelivr.net/gh/Lamitis/Natsume-Registry@main/registry.json` |
| 3 | ghfast.top | `https://ghfast.top/<原始地址>` |
| 4 | gh-proxy.com | `https://gh-proxy.com/<原始地址>` |
| 5 | gh.llkk.cc | `https://gh.llkk.cc/<原始地址>` |
| 6 | ghproxy.net | `https://ghproxy.net/<原始地址>` |

**插件包（Release 资产，5 个源，单源 30 秒）**

顺序是：自定义镜像 → 原始地址 → 上面 4 个加速前缀。插件包比 JSON 大得多，
所以单源超时放宽到 30 秒；每个镜像的响应都要**先校验 sha256 再落盘**。

非 GitHub 的地址不会被套加速前缀（这些镜像只代理 GitHub，套到别处只会 404）。

## 二、失败不算失败

单个源出现下面任一情况，只记一条原因并换下一个源，**不会弹错**：

- 超过超时时间；
- HTTP 状态码不是 200；
- 返回 200，但内容算出来的 sha256 与登记表不一致（镜像给坏包 / 传了一半）。

只有所有源都失败才抛 `SmartHttpException`，消息里带上每个源的原因，
例如「原始：HTTP 502 · 换下一个源；jsDelivr：超时（8s）」。
`SmartHttpException.originalUrl` 保留**未经加速的原始地址**，界面可以复制给
用户，让用户用浏览器下载后再走「导入插件」本地安装。

## 三、自定义镜像

设置 → 高级 → **网络加速** 里可以填一个自己的镜像，优先级**高于所有内置源**。
两种写法：

| 写法 | 例子 | 实际请求地址 |
| --- | --- | --- |
| 前缀 | `https://ghfast.top/` | `https://ghfast.top/https://github.com/...` |
| 模板 | `https://my.proxy/?url={url}` | `https://my.proxy/?url=https%3A%2F%2Fgithub.com%2F...` |

前缀模式会自动补尾斜杠；模板模式里的 `{url}` 会被 URL 编码后替换。
留空（或点「恢复自动」）= 只用内置池。

配置存在 `settings` 表的 `custom_mirror`，随整库备份一起迁移；
`AppState` 在启动加载与保存设置时把它同步给 `SmartHttpClient.instance`，
保存后立刻生效，不需要重启。

## 四、安全边界（务必读完）

1. **sha256 只保护插件包，不保护登记表本身**。登记表是明文 JSON，没有签名；
   镜像能加速它，也能替换它。所以镜像只能当作**传输通道**，不是新的信任根。
2. 下载域名白名单校验的是**登记表里的原始 URL**（只允许 GitHub 系），
   加速前缀只是客户端拼接出来的传输路径，不会让任意域名混进来。
3. 插件包一律「先校验、后解包」：哈希不一致的响应直接丢弃，不会落盘、
   不会进入 staging。
4. 自定义镜像建议用 https。http 镜像在同一网络里可被中间人替换响应；
   插件包仍有 sha256 兜底，但登记表内容会被改写。

## 五、排查

- 界面提示「插件登记表读取失败（已尝试 6 个源）：…」→ 逐条看原因：
  - 全是超时：网络整体不通，或被校园网/公司网拦截；
  - 全是 404：镜像临时不可用，稍后重试或换自定义镜像；
  - 只有 `sha256 不匹配`：镜像缓存了旧包，等它刷新或换源。
- 安装失败且提示里带「插件包下载失败」→ 到设置里复制原始下载地址，
  用浏览器下载 zip，再用「世界总览 → 导入插件」本地安装。

## 六、开发约定

- 新增镜像：只改 `SmartHttpClient.registrySources` / `acceleratorPrefixes`，
  顺序即优先级；登记表相关断言在 `test/smart_http_client_test.dart`。
- 其它需要访问 GitHub 的模块请复用 `SmartHttpClient.getFirst(...)`，
  不要各自写 `http.get`——否则超时策略与镜像池会分叉。
- 改动回退顺序或超时时，同步更新本文档与「网络加速」卡片的说明文案。
