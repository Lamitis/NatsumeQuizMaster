# NatsumeQuizMaster插件开发指南（world-overview）

> 版本：v1.39.2 · 面向第三方开发者。
>
> 需要**能力清单 / 目录结构 / `manifest.json` 字段 / 主程序 API / 动态加载方案**这类
> 更技术化的内容，请看根目录的 `PLUGIN_DEVELOPMENT.md`；本文保持「够用就好」的篇幅。

## 1. 插件是什么

插件是**声明式包**：一个 `plugin.json` 清单 + 可选资产。它**不执行任意代码**——
这是安全红线。插件能做的事被限制在 App 内置的「能力」清单里：

| 能力 | 说明 |
|---|---|
| `kb.search` | 检索知识库（给 AI 出题/解释提供资料） |
| `kb.read` | 读取知识库某篇文档全文 |
| `question.generate` | 基于知识库自动生成题目 |
| `bank.export` | 导出题库 |
| `question.tag` | 给题目打知识点标签 |

插件通过**提示词**（`prompt.md`）改变 AI 的行为（人设、出题风格、解释口径），
并可内置知识库文档与示例题库作为默认资产。

## 2. 目录结构

```
my-plugin/
├── plugin.json          # 必填：插件清单
├── prompt.md            # 可选：注入给 AI 的系统提示词
├── prompts/             # 可选：功能模板（宿主填槽后交给 AI，v1.37 起）
│   └── cheat_sheet.md
├── kb/                  # 可选：内置知识库文档（.txt/.md/.json）
│   └── 病理学笔记.md
└── sample_bank.json     # 可选：内置示例题库（NatsumeQuizMaster题库 JSON 格式）
```

打包成 `.zip`（可命名 `.natsume-plugin.zip`），在「世界总览 → 导入插件」安装。

## 3. plugin.json 字段

```json
{
  "id": "com.example.pathology-helper",
  "name": "病理学助教",
  "version": "1.0.0",
  "author": "你的名字",
  "description": "用教材口径讲解病理题，出题风格偏临床",
  "capabilities": ["kb.search", "question.generate"],
  "platforms": ["windows", "android"]
}
```

- `id`：唯一标识，建议用反向域名；重复安装会覆盖同 id 旧版。
- `capabilities`：声明所需能力（安装确认页会展示给用户）。
- `platforms`：可选，字符串数组，取值仅限 `windows` / `android` / `macos` / `linux`；缺省表示支持所有平台。
- 其余字段用于展示。

## 4. prompt.md 约定

内容会作为**系统提示词**注入到 AI 解释、追问与自动出题流程。建议包含：
- 角色与语气（如「你是病理学带教老师」）
- 出题/解释的口径（题型比例、难度、篇幅）
- 约束（「只依据知识库资料，不编造」——App 侧的知识库口径优先级更高，插件提示词不得覆盖）

## 4.1 功能模板 prompts/*.md（v1.37 起）

`prompt.md` 定「说话风格」，`prompts/*.md` 定「一次具体功能」。模板里写占位符，
**主程序查好数据再填进去**，插件不接触数据库、不联网、不执行代码。

当前唯一被消费的模板是 `cheat_sheet.md`（错题本右上角 ✨「考前小抄」）：

```markdown
按下面的错题做一份考前小抄，范围：{{SCOPE}}，日期：{{DATE}}。
- 按知识点分组，每组一句「一句话记住」+ 不超过 3 个易错点；
- 只写这些题涉及的内容；资料不足时写「资料未覆盖」。

薄弱知识点：{{KNOWLEDGE_POINTS}}

错题（共 {{ERROR_COUNT}} 道）：
{{ERROR_QUESTIONS}}
```

| 槽位 | 内容 |
| --- | --- |
| `{{ERROR_QUESTIONS}}` | 错题正文（题干 / 选项 / 正确答案 / 解析 / 错了几次，图片占位符已去掉） |
| `{{ERROR_COUNT}}` | 塞进模板的错题数（上限 10 道，按错得最多排序） |
| `{{SCOPE}}` | 当前筛选范围，如「错题 · 2 个题库」 |
| `{{DATE}}` | 本地日期 `2026-11-01` |
| `{{KNOWLEDGE_POINTS}}` | 知识点面板当前口径（前 6 项） |

要点：模板名 `cheat_sheet` / `cheat_sheet.md` / `prompts/cheat_sheet.md` 等价；
未知槽位原样保留（写错名字一眼能看出来）；没有已启用插件提供该模板时，
按钮只提示「去插件市场装插件」，不会偷偷换回宿主提示词。
单文件 ≤ 256KB，提示词会净化「忽略以上指令 / 切换身份」一类越权行。
细节见仓库根目录 `PLUGIN_DEVELOPMENT.md` §3.7。

## 4.2 UI 扩展（在界面上加按钮）

现在可以在 `plugin.json`（或 `manifest.json`）里配置 `ui_extensions`，让插件在
**答题页解析区**和**错题本右上角**自动渲染一个图标按钮。点击后由主程序取数、
填模板并调用 AI，结果以带免责声明的弹层展示；插件不需要（也拿不到）数据库与
网络权限。

```json
{
  "ui_extensions": [
    {
      "slot": "quiz_analysis_actions",
      "label": "深度解析",
      "icon": "psychology",
      "action": {
        "type": "ai_prompt",
        "contexts": ["question_text", "question_options", "correct_answer"],
        "prompt_template": "请解析这道题：\n{{QUESTION_TEXT}}",
        "renderer": "bottom_sheet_foldable"
      }
    }
  ]
}
```

- `slot`：`quiz_analysis_actions`（答题页解析区）/ `error_book_actions`（错题本右上角）；
- `contexts`：只填你真正需要的上下文切片，宿主会强制截断（题目 3000 字、错题最多 10 条）；
- `renderer`：`bottom_sheet`（默认）或 `bottom_sheet_foldable`（按 `<!--ANSWER_START-->` 折叠答案）；
- 清单可选 `platforms`（`windows` / `android` / `macos` / `linux`）；当前平台不在其中时按钮静默不渲染。

完整字段、可用槽位与安全边界见仓库根目录 `PLUGIN_DEVELOPMENT.md` §3.8。

## 5. 示例题库格式

与NatsumeQuizMaster题库导出格式一致（`BankFileService`）：

```json
{
  "format": "natsume-quiz-questions",
  "name": "示例题库",
  "questions": [
    {
      "title": "……",
      "options": ["A", "B", "C", "D"],
      "correct_answer": "A",
      "question_type": "single_choice",
      "analysis": "……",
      "knowledge_point": "病理学"
    }
  ]
}
```

## 6. 安全与审核

- 插件**不执行代码**：清单 + 提示词 + 资产文本，安装时展示能力摘要，用户确认后才装。
- 未来如需更强能力（脚本），会以独立沙箱解释器形式引入并单独授权；当前版本不提供。
- 请勿在插件内植入诱导性提示词；App 侧的「知识库约束」优先级高于插件提示词。

## 6.1 内置插件（v1.31 起）

App 自带**内置插件**，与第三方插件同表登记（`plugins` 表），但不走 zip 安装：

| 字段 | `natsume.notes`（v1.31） | `natsume.companion`（v1.32） |
|---|---|---|
| 名称 | 双链笔记 | 小鲸助教 |
| 许可 / 上游 | AGPL-3.0；格式与交互取形 [Logseq](https://logseq.com)（未引入其源码） | AGPL-3.0；陪伴交互取形 Coopanion（AGPL-3.0-or-later）与 Cortico（MIT），**不使用其鲸鱼娘贴图**（头像自绘 / 官方插件资产） |
| `syncable` | `true`（v1.35）—— 笔记随局域网同步，按设备可关 | `true`（v1.35）—— 人设与记忆可同步；**API Key / 好感度 / 悬浮位置不同步** |
| 启停 | 世界总览 → 插件区开关；关闭后「我的 → 学习工具 → 双链笔记」整条收起 | 同上；关闭后「我的 → 学习工具 → 小鲸助教」整条收起 |

清单定义在 `lib/services/plugins/builtin_plugins.dart`（`BuiltinPlugin` / `BuiltinPlugins`），
App 启动时 `ensureRegistered()` 幂等注册并保留用户已设的启停状态。

**同步边界（v1.35 起）**：`sync_repository.dart` 的快照新增 `plugins` 块，按插件逐项
带上笔记 / 待办 / 助教人设与记忆；开关在「设置 → 同步与提醒 → 插件内容同步」，
**每台设备各自决定**（本机选择不随快照传播）。合并口径：按 `uid` 认行、`updated_at`
新的赢，出链只增不删。「只同步题库（分享给别人用）」模式一律不带插件内容。
若你自制插件需要跨端数据，请在插件说明里明确写清「本机 / 可同步」。

**官方插件资产**：内置插件自带的素材统一放 `assets/plugins/official/<插件 id>/` 下，
只把**运行时真正要读的文件**注册进 `pubspec.yaml`（目录条目不递归），原始母版
（如 `companion/masters/*.ico`）留在仓库里不打包，避免包体为存档买单。

## 7. 世界（World）

「世界」是**知识库 + 题库 + 插件** 的打包单元（`.natsume-world`，本质 zip）。
导出：把当前所有知识库、题库、插件打进一个文件分享；导入：一键还原。
适合「把一门课的完整备考环境发给同学」。

## 8. 插件表与下载加速（v1.36 起）

客户端拉 `registry.json` 与下载 Release 资产时会**按顺序自动换源**
（原始 → jsDelivr → 多个 GitHub 加速前缀），单源超时、sha256 不一致都会
自动换下一个，用户不需要手动重试。细节见 [`网络加速.md`](./网络加速.md)。

对插件作者只有三条要求：

1. 发布包后**不要再改同名资产**——`sha256` 一旦变化，老客户端会把它当坏包丢弃；
   升级请发新版本 + 新 `sha256`。
2. 下载地址仍必须是 **https 的 GitHub 系域名**（白名单在客户端硬编码，
   加速前缀由客户端拼接，不接受第三方直链）。
3. 加速镜像只负责传输：**它们不是信任根**，客户端只认登记表里的 sha256。
