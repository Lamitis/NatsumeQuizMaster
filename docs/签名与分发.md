# 签名与分发说明

> 面向开发者：如何给「NatsumeQuizMaster」签名、消除系统安装警告、并保持防篡改校验一致。

## 现状

- 包名 `com.natsume.quiz`，debug / release 签名配置见 `android/key.properties`。
- release 未购买代码签名证书 → Windows SmartScreen「已保护你的电脑」、
  Android「未知来源」警告。
- 防篡改：`lib/services/integrity_service.dart` 锁定签名 SHA-256 前 16 位，Android
  端经 MethodChannel 校验（`MainActivity`）。

## Android 签名

1. 生成自有 release keystore（**私钥不入库，加入 `.gitignore`**）：
   ```bash
   keytool -genkey -v -keystore ~/natsume-release.jks \
     -alias natsume -keyalg RSA -keysize 2048 -validity 10000
   ```
2. 配置 `android/key.properties`（或环境变量）：
   ```
   storeFile=/path/to/natsume-release.jks
   storePassword=...
   keyAlias=natsume
   keyPassword=...
   ```
3. 构建并签名：
   ```bash
   flutter build apk --release --obfuscate --split-debug-info=build/symbols
   ```

## Windows 签名

- 用 `signtool` 自签证书可消除「未签名」字样，但**仍会触发 SmartScreen**——
  需要 EV/OV 代码签名证书或积累信誉才会「全绿」。
- 学习/内部使用：自签 + 文档教用户「更多信息 → 仍要运行」即可。
- 正式分发：考虑 **Azure Trusted Signing**（云签名，成本低于买证书）或购买
  OV/EV 证书后用 `signtool sign`。

## 私钥与防篡改

- 私钥/keystore 永远不入库；换签名后需同步更新 `integrity_service.dart` 里锁定的
  SHA-256 前 16 位，否则 App 会判定「被篡改」并显示红页。
- 发布产物附 `SHA256SUMS.txt` 供用户核对（见 README「安装与校验」）。
