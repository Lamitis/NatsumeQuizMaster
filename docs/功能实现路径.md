## 1. 应用入口与启动链

| 功能 | 实现路径 |
|---|---|
| 进程入口 | `lib/main.dart` `main()` |
| 防篡改校验 | `lib/services/integrity_service.dart` `IntegrityService.verify()`（kDebugMode 放行；Android 走 MethodChannel `com.natsume.quiz/integrity`，原生在 `android/.../MainActivity.java` `configureFlutterEngine`；比对签名 SHA-256；结果记录为 `IntegrityStatus`，不硬性阻断启动，仅静默限制部分高级功能） |
| 数据初始化失败兜底 | `main.dart` `_DbErrorApp`（数据库打不开时恢复页：重置数据库 `DatabaseService.resetDatabase()` / 退出） |
| 主题恢复 | `main.dart` → `ThemeService.init()`（SharedPreferences `app_theme`） |
| 提醒服务启动 | `main.dart` → `ReminderService.init()` + `syncSchedule()` + `catchUpReminderIfMissed()` |
| 启动闪屏 | `lib/screens/splash_screen.dart`（Logo + 「NatsumeQuizMaster」+ 「今日一言」+ 加载圈，1.4 秒后 `pushReplacement`；一言失败回退默认文案；**首启判定与一言并行读取，不阻塞进入**） |
| 首启分流 | `splash_screen.dart` `SplashScreen.nextScreen(firstRun:)`（首启 → `MainShell(startTour: true)`，其余 → `MainShell()`；判定状态 `lib/services/guide_service.dart`，SharedPreferences `first_run_guide_seen_v2`，读失败按「已看过」不拦路） |
| 使用引导（互动式，跨页面连续） | **不是说明页，而是在真实界面上逐步带操作，并且会跟着用户进二级页面**：`lib/widgets/guide/guide_host.dart`（在 `MaterialApp.builder` 里把遮罩 + `GuideScope` 挂到 **Navigator 之上**——push 出来的导入页、`NatsumeSheet` 弹窗都在引导覆盖之下）+ `guide_tour.dart`（四块遮罩夹出一个「洞」，洞里的真实控件照常可点；气泡随洞换位，每步淡入）+ `guide_step.dart` / `guide_steps.dart`（13 步真实动线：首页进度 → 底部四 Tab（用户自己点「开始」即自动前进）→ 开始页三个入口 → **点进错题本页看一眼再返回** → 统计 → 我的 → **点进设置中心看一眼再返回** → **真的点进导入页的「一键导入示例题库」** → 自由选题 → 弹窗里的「开始」；二级页那两步锚在返回键上，因为返回键在加载 / 空态 / 有数据三态都存在，而错题本首启必是空态、锚筛选栏会一直等不到；导航步（点高亮处会推出新页面）标 `GuideStep.awaitAction` 不出「下一步」按钮，`GuideStep.fallbackAnchorIds` 给「同页两种形态」留备选锚点）+ `guide_anchor.dart`（`GuideScope` + `GuideAnchor`；每个锚点实例自带 GlobalKey，注册表按「最上层路由」挑可见实例取屏幕矩形，因此同 id 双实例不会撞 key；未就绪先重试、锚点缺失退化成居中气泡）+ `guide_controller.dart`（唯一状态源 + `GuideRouteObserver`：路由一变就判断「下一步的目标是否已出现」，出现即顺势前进；新页面可能还在异步加载（错题本首帧是骨架屏），此时登记 `tickPendingFollow()` 由引导层每次重试时催一次，等锚点出现再前进；末步的跳转即收尾并落「已看过」）；入口二：我的页 →「重看使用引导」（`GuideScope.maybeOf(context)?.start()`，不推新页面） |
| 主壳四 Tab | `lib/screens/main_shell.dart`（IndexedStack 保活：首页/开始/统计/我的；切 Tab 回调 `refreshWeeklyStats` / `StatsTabState.refresh`；宽屏改左侧 NavigationRail） |

## 7. 刷题三模式（统一答题页 `lib/screens/quiz_screen.dart`）

| 功能 | 实现路径 |
|---|---|
| 抽题 | `lib/services/quiz_service.dart` `startQuiz(bankIds, mode, questionCount, noShuffle, persistSession, knowledgePoints?, questionTypes?)` → `DatabaseService.getQuestionsByBanks(..., random: !noShuffle, knowledgePoints:, questionTypes:)`（SQL `ORDER BY RANDOM()`；空集合 = 不限，知识点空串 = 「未分类」）→ 数量截取（不足全用/超量 take N）→ 会话落库（`persistSession`） |
| 会话状态 | `AppState.startQuiz`（选库/数量 → 填充 `quizQuestions`）/ `startQuizWith`（显式题库范围，题库题号网格用）/ `startQuizWithFilter`（+ 知识点与题型筛选，自由选题面板用）→ `QuizScreen` |
| 自由选题面板（2026-10-29，题型筛选 2026-10-29 补） | `lib/widgets/quiz_setup_sheet.dart` `QuizSetupSheet.show(context, appState)` → `QuizSetupResult`（bankIds / knowledgePoints / questionTypes / count / mode / noShuffle）：题库多选（全选 / 反选 / 清空 +「已选 N 库 M 题」）→ 知识点多选（`AppState.getKnowledgePointsByBanks` 随题库联动，空知识点显示「未分类」）→ 题型多选（七种，标签走 `Question.labelOfType`，不选 = 全部）→ 题量 chips → 三种模式 +「按题库原顺序出题」→「开始」；开始页 `_showStartQuizSheet` 唤起，随后 `QuizLauncher.launch(bankIds:, count:, noShuffle:, knowledgePoints:, questionTypes:)` |
| 左右滑动切题 | `GestureDetector.onHorizontalDragEnd`（velocity ±300：左滑前进/右滑后退；刷题/背题需已答才前进，练习自由） |

| 重新作答 | 已答视图「重新作答」按钮 → `AppState.resetCurrentAnswer()` → 再提交走 `QuizService.resubmitAnswer`（**更新原记录不新增**，会话统计差量修正 + FSRS 补记） |
| 解析/追问 | `AppState.showAnalysis/regenerateAnalysis` → `AIService.getAnalysis`（缓存 `ai_cache`，失败串不缓存）/`askFollowUp`（mounted 检查） |
| 收藏 | 底部「错题本」按钮 → `AppState.toggleErrorBook`（`error_book` 表） |

| 功能 | 实现路径 |
|---|---|
